## Project Purpose

The purpose of this project is to develop a Machine Learning model capable of classifying Iris flower species using the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The project includes an interactive Streamlit dashboard that allows users to visualize the dataset, evaluate model performance, and predict flower species.

- Scikit-learn
- Plotly
